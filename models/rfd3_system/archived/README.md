# Archived RFD3 Reference Material

This directory contains copied upstream RFdiffusion3 documentation, examples,
tutorial assets, and images that were inherited when `rfd3_system` was created
from `models/rfd3`.

These files are retained for reference only. They are not part of the active
`rfd3_system` workflow, should not be used as examples for the shared-chain
prototype, and should not be referenced by runtime code.

Active prototype documentation lives in:

```text
../README.md
../docs/superdiff_shared_chain.md
../docs/examples/superdiff_shared_chain_proxy.yaml
```
